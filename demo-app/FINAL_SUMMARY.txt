================================================================================
                         TROUBLESHOOTING
================================================================================

DATABASE CONNECTION FAILED
→ Check DATABASE_URL in .env.local
→ Test: psql $DATABASE_URL
→ Create DB: createdb fluid_demo

LLM API KEY ERROR
→ Add ANTHROPIC_API_KEY or GEMINI_API_KEY to .env.local
→ Get key from console.anthropic.com or aistudio.google.com

GENERATION TOO SLOW
→ First time: 8-15s (normal)
→ Cached: <50ms
→ Prompt cache: 5-10s

CHAT NOT WORKING
→ Check DATABASE_URL is set
→ Run: bun run db:push
→ Verify tables: bun run db:studio
